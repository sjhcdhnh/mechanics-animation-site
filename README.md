# 理论力学动画演示平台 🎬
一个集力学动画演示、互动评论、管理员后台于一体的在线展示平台，用Next.js构建，专注于用生动的动画讲解生活中的力学知识。

## ✨ 核心功能
- 🎥 **力学动画演示**：包含天体运动、羽毛球运动、机构传动等多类力学场景动画，直观展示力学原理
- 💬 **互动评论系统**：用户可对动画发表评论、交流学习心得
- 📱 **响应式设计**：完美适配电脑、平板、手机等多端设备

## 🛠️ 技术栈
- **框架**：Next.js 14 + TypeScript
- **样式**：Tailwind CSS
- **部署**：Vercel（全球CDN、自动HTTPS、一键部署）
